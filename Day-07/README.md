## 🛠️ Section 1: Wildcards (Globbing)

Wildcards are special characters used in commands to represent one or more characters, allowing users to select multiple files at once.

| Wildcard | Description | Example | Matches |
| :--- | :--- | :--- | :--- |
| **Asterisk (`*`)** | Matches any number of characters (including zero characters). | `*.txt` | Matches all files ending with `.txt` |
| **Question Mark (`?`)** | Matches exactly one character. | `file?.txt` | Matches `file1.txt`, `fileA.txt` |
| **Square Brackets (`[]`)** | Matches any single character enclosed within the brackets. | `file[12].txt` | Matches `file1.txt` and `file2.txt` |
| **Curly Braces (`{}`)** | Matches a group of comma-separated patterns. | `file{1,2}.txt` | Matches `file1.txt` and `file2.txt` |

---

## 🛠️ Section 2: Linux Redirection & File Descriptors

In Linux, a **File Descriptor** is an integer that represents an open file or stream. The system uses these descriptors to determine where to read input from or send output/error data to.

| Stream Name | Standard Identifier | File Descriptor | Description |
| :--- | :--- | :--- | :--- |
| **Standard Input** | `stdin` | `0` | Default stream for command input (usually keyboard) |
| **Standard Output** | `stdout` | `1` | Default stream for successful command output (usually terminal screen) |
| **Standard Error** | `stderr` | `2` | Default stream for error messages generated by commands |

## 💻 Practice Execution Log

```bash
# Wildcard Matching Examples
$ ls *.txt                     # Lists all .txt files
$ ls file?.txt                 # Lists files like file1.txt, file2.txt
$ ls file[12].txt              # Matches file1.txt and file2.txt specifically
$ touch file{1,2}.txt          # Creates file1.txt and file2.txt simultaneously

# I/O Redirection Examples
$ echo "Hello World" > output.txt    # Redirects stdout (1) to file (overwrites)
$ echo "New Line" >> output.txt      # Appends stdout (1) to file
$ ls non_existent_file 2> error.log  # Redirects stderr (2) to error.log
$ cat < input.txt                    # Redirects stdin (0) from input.txt
